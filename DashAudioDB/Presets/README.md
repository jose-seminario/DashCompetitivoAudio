# DashAudioDB — Presets Base de Referencia

Plantillas genéricas listas para importar y utilizar como punto de partida:

- `flat_reference.json`: Respuesta totalmente plana (DSP transparente sin alteración de balance tonal).
- `tactical_footsteps.json`: Preconfiguración acústica táctica genérica para cualquier juego competitivo.
