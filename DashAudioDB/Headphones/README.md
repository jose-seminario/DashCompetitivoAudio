# DashAudioDB — Calibración de Auriculares

Esta sección almacena las curvas de corrección acústica para auriculares comerciales hacia curvas target universales (Harman Over-Ear 2018 y Diffuse Field).

## Modelos y Estado de Calibración
- **Razer BlackShark V2 X**: `uncalibrated_pending_verified_measurement`. No se inventan curvas acústicas; se mantiene el perfil base sin filtros hasta contar con mediciones de laboratorio verificables (Gras 43AG / BK 5128).
- **HyperX Cloud II**: `verified` con filtros paramétricos AutoEq hacia target Harman 2018 (licencia MIT).
- **Logitech G Pro X**: `verified` con filtros paramétricos AutoEq hacia target Harman 2018 (licencia MIT).
