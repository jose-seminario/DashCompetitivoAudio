# DashAudioDB — Perfiles Espaciales y HRTF/HRIR

Esta sección contiene perfiles espaciales optimizados para renderizado binaural tridimensional en auriculares:

1. **HRTF Woodworth Reference**: Síntesis analítica de respuesta a impulsos en tiempo real con cero latencia y filtros de sombra de cabeza (head-shadow).
2. **HeSuVi Adapter Profile**: Mapeo estandarizado para cargar respuestas al impulso WAV locales de 14 canales provenientes del ecosistema HeSuVi.
